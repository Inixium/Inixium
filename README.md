# Избранные проекты

## ReserveMe

Fullstack-платформа для бронирования столиков в ресторанах.

Проект включает:

- каталог ресторанов;
- поиск и фильтрацию;
- систему бронирования;
- выбор столика;
- личный кабинет пользователя;
- административную панель;
- JWT-аутентификацию.

Стек:

`Next.js` `React` `TypeScript` `FastAPI` `Python`

Демо:
https://reserve-me.online/

GitHub:
https://github.com/Inixium/reserveme
